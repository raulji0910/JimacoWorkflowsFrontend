Puede buscar y devolver cualquier documento

Permiso administrativo: quien tenga este rol puede buscar cualquier OC (sin importar el paso en que esté ni si tiene el rol habilitado ahí) y devolverla al emisor — anula el paso en curso y la deja "en espera de aprobación" en World Office, para que se pueda editar y relanzar.

Puede gestionar el alistamiento

Puede registrar la cantidad disponible de cada ítem en cualquier Hoja de Alistamiento, y ver el dashboard de alistamiento — sin importar el paso actual de la OC (pensado para Transporte).

Puede ver las cuentas por pagar

Ver lo que se les debe a los proveedores según World Office y decidir qué facturas se mandan a pagar (pensado para Gerencia Comercial).

Pagador de cuentas

Menú "Pagos": recibe las relaciones de pago y los pagos extraordinarios, elige qué pagar como un lote (un solo soporte) y rechaza lo que no. Pensado para Gerencia General.

Puede gestionar entregas

Menú "Entregas": ve las remisiones contabilizadas, las imprime y confirma la entrega adjuntando la remisión firmada por el cliente (foto o escaneo). Pensado para Logística.

Puede ver el estado de las entregas

Solo consulta qué remisiones están por entregar o entregadas y sus soportes, sin confirmar entregas.

Puede adjuntar documentos para facturar

Para quien elabora las remisiones (vendedoras): ve SUS remisiones (por su "Usuario WO"), le llega el correo cuando se entregan, adjunta la OC, la entrada de almacén, etc. y las envía a contabilidad.

Puede facturar entregas (contabilidad)

Le llega el correo cuando una remisión está lista para facturar, ve todas las remisiones con sus documentos y puede devolverlas al emisor con un comentario.

Puede ver el alistamiento de Ferrealiados
